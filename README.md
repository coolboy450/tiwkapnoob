# ติวกับนูบ

ข้อสอบแนวสอบเข้า ม.1 วิชาคณิตศาสตร์และวิทยาศาสตร์ จับเวลาเหมือนสนามจริง ตรวจให้อัตโนมัติ พร้อมคะแนนแยกหัวข้อและเฉลยทีละขั้น เว็บแอปไฟล์นิ่ง ใช้ฟรี ไม่มีบัญชีผู้ใช้

> ข้อสอบทั้งหมดเป็น **ข้อสอบแนว** ที่แต่งขึ้นใหม่ **ไม่ใช่ข้อสอบจริงของโรงเรียนใด** และไม่เกี่ยวข้องกับโรงเรียนที่กล่าวถึง จำนวนข้อและเวลาเป็นรูปแบบโดยประมาณ

## หน้า
- `index.html` แอปของเด็ก: เลือกชุด → ชื่อเล่น + รหัสห้อง → ทำข้อสอบ → ผลและเฉลย
- `index.html?preview=1` ดูชุดที่ยังไม่ผ่านการตรวจ (ไม่ส่งคะแนน)
- `teacher.html` หน้าตรวจของครู: ติ๊กถูก/ต้องแก้ ใส่โน้ต คัดลอกผลตรวจ

## เนื้อหา
- `sets/index.json` รายการโรงเรียนและชุดข้อสอบ ชุดที่ `"reviewed": false` เด็กจะมองไม่เห็น
- `sets/<id>.json` ข้อสอบ: `type` เป็น `mc` (4 ตัวเลือก, `answer` = ตำแหน่ง 0–3) หรือ `num` (`answer` เป็นตัวเลขหรือเศษส่วน)
- ข้อความรองรับสูตรใน `$...$` (KaTeX) และขึ้นบรรทัดใหม่ด้วย `\n`

## คะแนนเข้า Google Sheet
ดู `docs/ตั้งค่า-google-sheet.md` แล้วใส่ URL ใน `assets/config.js`
เก็บเฉพาะชื่อเล่น รหัสห้อง และคะแนน ไม่เก็บชื่อจริง เบอร์โทร อีเมล หรือชื่อโรงเรียนของเด็ก

## ข้อจำกัดที่รู้อยู่
เป็นเว็บไฟล์นิ่ง คำตอบอยู่ในไฟล์ข้อสอบที่เบราว์เซอร์โหลด คนที่ตั้งใจเปิดดูโค้ดก็หาคำตอบเจอได้ จึงเหมาะกับการฝึกและ pre-test ไม่เหมาะกับการสอบที่มีผลจริง
