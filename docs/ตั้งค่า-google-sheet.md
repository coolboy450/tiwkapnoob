# ตั้งค่า Google Sheet รับคะแนน (ทำครั้งเดียว ราว 5 นาที)

คะแนนจะเข้า Google Sheet **ของคุณเอง** ไม่ผ่านใคร ฟรี ใช้บัญชี Google ปกติได้

## 1. สร้าง Sheet และวางโค้ด
1. เปิด https://sheets.new สร้างสเปรดชีตใหม่ ตั้งชื่อเช่น `ติวกับนูบ คะแนน`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้ง แล้ววางโค้ดทั้งหมดจากไฟล์ `apps-script/Code.gs` ของโปรเจกต์นี้ กดบันทึก (ไอคอนแผ่นดิสก์)
4. ด้านบนเลือกฟังก์ชัน `setup` แล้วกด **เรียกใช้ (Run)**
   - Google จะถามสิทธิ์ กด **ตรวจสอบสิทธิ์** เลือกบัญชีของคุณ
   - ถ้าขึ้น "Google ยังไม่ได้ยืนยันแอปนี้" กด **ขั้นสูง → ไปที่ (ชื่อโปรเจกต์)** ได้ เพราะเป็นโค้ดของคุณเอง
   - เสร็จแล้วกลับไปที่ Sheet จะมีชีต `ห้อง` และ `คะแนน` เพิ่มมา

## 2. ใส่รหัสห้อง
ในชีต `ห้อง` คอลัมน์ A ใต้หัวตาราง ใส่รหัสห้องที่จะให้เด็กใช้ ทีละแถว เช่น
```
P6A
P6B
```
เด็กที่ใส่รหัสไม่ตรง คะแนนจะไม่เข้า Sheet (แต่เด็กยังเห็นคะแนนของตัวเองในแอปเหมือนเดิม)

## 3. เปิดให้แอปส่งคะแนนเข้ามา
1. ในหน้า Apps Script กด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
2. ไอคอนเฟือง เลือกประเภท **เว็บแอป**
3. ตั้งค่า
   - **เรียกใช้ในฐานะ:** ฉัน (บัญชีของคุณ)
   - **ผู้ที่มีสิทธิ์เข้าถึง:** ทุกคน
4. กด **ทำให้ใช้งานได้** แล้วคัดลอก **URL ของเว็บแอป** (ขึ้นต้นด้วย `https://script.google.com/macros/s/...`)
5. ส่ง URL นี้ให้ noob_dev ใส่ในแอป (`assets/config.js`) URL นี้ไม่ใช่รหัสผ่าน ใครมีก็ส่งคะแนนเข้ามาได้ แต่โค้ดรับเฉพาะรหัสห้องที่อยู่ในชีต `ห้อง`

> "ทุกคน" หมายถึงแอปของเด็กส่งคะแนนเข้ามาได้โดยไม่ต้องล็อกอิน **ไม่ได้แปลว่าใครก็เปิดดู Sheet ได้** Sheet ยังเป็นของคุณคนเดียว

## ถ้าแก้โค้ดทีหลัง
ต้อง Deploy ใหม่: **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข (ดินสอ) → เวอร์ชัน: ใหม่ → ทำให้ใช้งานได้** URL เดิมยังใช้ได้

## เก็บข้อมูลอะไรบ้าง
เวลาส่ง รหัสห้อง ชื่อเล่น ชุดข้อสอบ ครั้งที่ คะแนน เวลาที่ใช้ คะแนนแยกหัวข้อ และคำตอบแต่ละข้อ **ไม่มี**ชื่อจริง เบอร์โทร อีเมล หรือชื่อโรงเรียนของเด็ก

## อัปเดตสคริปต์ (เมื่อมีเวอร์ชันใหม่ เช่น เพิ่มอันดับในห้อง)
1. เปิดสคริปต์ใน Apps Script (ส่วนขยาย → Apps Script) ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดใหม่ทั้งหมดจากไฟล์ `apps-script/Code.gs` ของโปรเจกต์ (หรือลิงก์ https://raw.githubusercontent.com/coolboy450/tiwkapnoob/main/apps-script/Code.gs) กดบันทึก
2. **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ไอคอนดินสอ → เวอร์ชัน: เวอร์ชันใหม่ → ทำให้ใช้งานได้**
3. URL เดิมยังใช้ได้ ไม่ต้องส่งใหม่

สคริปต์ใหม่ให้แอปเช็กรหัสห้อง และดึงอันดับในห้อง (แสดงเฉพาะชื่อเล่นกับคะแนนที่ดีที่สุด) ต้องรู้รหัสห้องที่อยู่ในชีต ห้อง ถึงจะดูอันดับได้
